### 技術深挖 (Technical Deep Dive)

#### 三層訊息模型
```
Layer 1: Locale (zh-hant.ts / en.ts) - 所有積木的自然語言
Layer 2: Style Overlay (style/engineer.ts) - 僅核心積木的 C++ 語法
Layer 3: UI i18n (ui/src/lib/i18n/) - 選單、按鈕等 UI 文字
```

#### 風格切換流程
1. `setBlockStyle('engineer', 'zh-hant', workspace)`
2. 載入 `ZH_HANT_MESSAGES` 到 `Blockly.Msg`
3. 疊加 `ENGINEER_STYLE` 覆寫特定鍵值
4. 呼叫 `workspace.refreshToolboxSelection_()` 更新 UI
5. **不需重載工作區**，積木文字即時更新

#### 與 piBlockly 的關鍵差異
- piBlockly 使用 `_ENGINEER` / `_ANGEL` 兩組完整語言檔
- CodeBridge 使用 Locale + Style Overlay，感測器積木不受風格影響
- 模組載入器相容 piBlockly-modules 格式
