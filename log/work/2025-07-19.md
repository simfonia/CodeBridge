### 2. i18n 文字顯示修復
**問題**：`%{BKY_TLB_...}` 顯示為原始文字而非翻譯
**解法**：
- 建立 `ui/src/i18n.js` 模組
  - 定義 `zhHant` 與 `en` 翻譯物件
  - `initI18n()`：註冊翻譯到 `Blockly.Msg`
  - `replaceBkyPlaceholders()`：用 TreeWalker 替換 DOM 文字節點
  - `replaceBkyTitles()`：替換元素 `title` 屬性
  - `detectLocale()`：自動偵測瀏覽器語系
- `ui/index.html`：在 `main.js` 之前載入 `src/i18n.js`
- `ui/src/main.js`：DOMContentLoaded 時呼叫 `CodeBridgeI18n.init()`

## 技術深挖 (Technical Deep Dive)

### CSS Flex 布局陷阱
- `flex: 1` 與 `width: 50%` 同時使用會造成分配衝突
- 解法：子元素加入 `min-width: 0` 或 `flex-shrink: 0`
- `#blocklyDiv` 必須加入 `min-height: 0` 否則 flex 子元素不會收縮

### i18n 三層字串意識
1. **Cline API Payload**：我傳遞的指令
2. **磁碟上的 .js 檔案**：`i18n.js` 中的字串
3. **執行後 return 的字串**：最終顯示在畫面上的文字
- 確保 `\n` 符號在第二層保持為字面量，直到第三層才變為真正的換行符

### Dropdown Hover Gap 問題
- 選單與觸發按鈕之間有 4px gap（`margin-top: 4px`）
- 滑鼠移動經過 gap 時會觸發 `:hover` 失效
- 解法：`::before` 偽元素從選單頂部向上延伸 10px，形成無形橋樑
