CodeBridge Toolbar 與 .cbg 專案

公開 API用途位置
CodeBridgeTauri.isAvailable()Tauri runtime 是否可用；純瀏覽器環境為 false，呼叫端須降級為 disabled 或提示。ui/src/lib/tauri/bridge.js
CodeBridgeTauri.invoke(command, args)呼叫 Rust command。ui/src/lib/tauri/bridge.js
CodeBridgeTauri.describeError(error)把 Rust 的 KEY|detail 錯誤拆成 i18n key 與補充說明。ui/src/lib/tauri/bridge.js
CodeBridgeTauri.pickProjectToOpen() / pickProjectSavePath(name)開啟／另存新檔對話框（僅 .cbg），使用者取消回傳 null。ui/src/lib/tauri/bridge.js
CodeBridgeProject.EXT / FORMAT_VERSION副檔名 .cbg 與格式版本的單一常數來源。ui/src/lib/project/project-store.js
CodeBridgeProject.serialize(xml, meta)把 cbp: metadata 注入 Blockly XML 根元素（冪等）。ui/src/lib/project/project-store.js
CodeBridgeProject.parse(xml)解析 .cbg，回傳 { meta, body }（body 為移除 metadata 的乾淨 XML）。ui/src/lib/project/project-store.js
CodeBridgeProject.isSupported(meta)格式版本過新時回 false，呼叫端須拒絕開啟。ui/src/lib/project/project-store.js
CodeBridgeProject.createStore({ storage })建立專案狀態：getState / isDirty / refresh / markSaved / markUntitled / getSnapshot / subscribe。ui/src/lib/project/project-store.js
store.addRecent / getRecents / removeRecent / clearRecents最近專案清單（上限 RECENTS_LIMIT = 10，依路徑去重）。ui/src/lib/project/project-store.js
store.setDraft / getDraft未儲存草稿（localStorage），供重載後還原並標記 dirty。ui/src/lib/project/project-store.js
CodeBridgePlainCode.strip(code)去除 ID 標記得到可寫檔／可貼 Arduino IDE 的 plain code；保留原結尾換行。ui/src/lib/project/plain-code.js
CodeBridgePlainCode.buildPatterns() / extractIds(line) / stripLine(line)程式碼預覽的標記解析與去除（與 strip 共用同一套 regex）。ui/src/lib/project/plain-code.js
CodeBridgeProjectIO.init({...})注入專案流程依賴：store / getWorkspace / getCode / injectDefaultBlocks / onWorkspaceReloaded。ui/src/lib/project/project-io.js
CodeBridgeProjectIO.save / newProject / openProjectDialog / openPath / openExample / copyCode專案與複製流程的編排，含未儲存變更確認。ui/src/lib/project/project-io.js
CodeBridgeProjectIO.serializeWorkspace() / loadWorkspaceXml(xml)工作區 ↔ XML 的雙向轉換。ui/src/lib/project/project-io.js
CodeBridgeToolbarUI.init({ store })綁定 data-action、渲染最近清單與範例、同步 dirty 指示、beforeunload 攔截。ui/src/lib/ui/toolbar.js
CodeBridgeToolbar.actions按鈕 registry：{ id, implemented, handledBy, labelKey }。ui/src/lib/ui/toolbar-registry.js
CodeBridgeConfirm.askUnsaved(name)未儲存變更三選一（儲存／不儲存／取消），回傳 'save' | 'discard' | null。ui/src/lib/ui/confirm-dialog.js
CodeBridgeClipboard.copy(text)複製到剪貼簿，navigator.clipboard 失敗時退回 execCommand('copy')。ui/src/lib/ui/clipboard.js
CodeBridgeToast.show(text, { type, duration }) / showKey(key)短暫提示（已儲存／已複製／錯誤）。ui/src/lib/ui/toast.js

Rust command

Command說明
project_read(path)讀取 .cbg；非 .cbg 或不存在時回 PROJECT_ERROR_INVALID_EXTENSION|／PROJECT_ERROR_NOT_FOUND|。容忍 UTF-8 BOM。
project_save(path, contents)寫入 UTF-8 無 BOM、LF 行尾；副檔名白名單阻擋誤覆寫其他檔案。
project_exists(path)檢查檔案是否存在（過濾失效的最近清單）。

持久化鍵

  • codebridgeProject：目前專案路徑、檔名、最後儲存的工作區 XML 快照與 metadata。
  • codebridgeProjectDraft：未儲存草稿（每次變更 debounce 150ms 寫入）。
  • codebridgeRecentProjects：最近專案清單 JSON 陣列。

按鈕契約

  • index.html 每個 .toolbar-btn／.terminal-tool-btn 都必須有 data-action 且在 registry 有對應項。
  • 未實作按鈕在 HTML 必須帶 disabled，並列入 toolbar-buttons.test.js 的 FROZEN_UNIMPLEMENTED_IDS。
  • 目前凍結清單：btn-refresh-serial、btn-run、btn-stop、btn-terminal、btn-pause-terminal、btn-clear-terminal、btn-close-terminal。

.cbg 檔案格式

<?xml version="1.0" encoding="UTF-8"?>
<xml xmlns="https://developers.google.com/blockly/xml"
     xmlns:cbp="https://codebridge.app/xml"
     cbp:format="1" cbp:name="Blink"
     cbp:fqbn="arduino:avr:uno" cbp:port="COM3" cbp:baud="9600">
  <block type="initializes_setup" id="..." x="20" y="20">...</block>
</xml>
  • 積木 XML 是唯一真實來源；.ino 永遠是產物，不落地。
  • ID 標記（// __BLOCKLY_ID:<id>__、/* // __BLOCKLY_ID:<id>__ */）只存在於記憶體中的 marked code，絕不寫入磁碟。
