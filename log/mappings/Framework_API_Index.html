CodeBridge Blockly 13.3.0 API Index

本文件記錄已在 CodeBridge 實際 runtime 驗證的 Blockly v13 API。

API用途CodeBridge 位置
Blockly.VERSION確認執行期核心版本，應為 13.3.0。runtime smoke test
Blockly.inject(element, options)建立工作區；CodeBridge 使用 renderer: 'thrasos'、theme: Blockly.Themes.Classic、sounds: false。ui/src/main.js
Blockly.setLocale(messages)先套用 Blockly 官方基礎訊息，再由模組訊息覆寫。ui/src/lib/blockly/loader.js
Blockly.Xml.domToWorkspace(xml, workspace)載入 v12／v13 Blockly XML。ui/src/main.js、loader.js
Blockly.Xml.workspaceToDom(workspace)保存工作區 XML。ui/src/main.js、loader.js
Blockly.Arduino.forBlock[type]註冊 CodeBridge Arduino generator。ui/src/lib/blockly/modules/*/generators.js
Blockly.Arduino.workspaceToCode(workspace)產生 setup、loop 與 code buckets 內容。ui/src/main.js
Blockly.Blocks[type]註冊自訂與覆寫積木；本專案維持既有註冊方式。ui/src/lib/blockly/modules/*/blocks.js

v13 注意事項

  • Core-only 檔案必須搭配官方 msg/en.js 或 msg/zh-hant.js，否則工作區 ARIA 初始化缺少訊息。
  • sounds: false 會跳過 Blockly media 音效載入。
  • Thrasos 是 renderer 名稱；公開 Theme 仍為 Classic 或 Zelos。
  • v12 已棄用的 Workspace／VariableMap 舊 API 已於 v13 移除，新程式應使用 VariableMap API。
