CodeBridge Theme Module

公開 API用途位置
CodeBridgeTheme.init()讀取、遷移並套用目前的 Engineer／Angel preset。ui/src/theme/theme-manager.js
CodeBridgeTheme.setPreset(id)協調 block style、視覺 theme、持久化與 Blockly palette。ui/src/theme/theme-manager.js
CodeBridgeTheme.getPreset()取得目前 preset ID。ui/src/theme/theme-manager.js
CodeBridgeTheme.attachWorkspace(workspace)將目前 Blockly theme 與 palette 套用到工作區。ui/src/theme/theme-manager.js
CodeBridgeBlocklyTheme.getTheme(visualTheme)建立／取得 Blockly component theme。ui/src/theme/blockly-adapter.js
CodeBridgeBlocklyTheme.applyPalette(visualTheme, workspace)更新既有 block、toolbox 與新 block 的 palette。ui/src/theme/blockly-adapter.js
CodeBridgeCodeTheme.apply(visualTheme)套用程式碼預覽 visual theme。ui/src/theme/code-theme-adapter.js
data-codebridge-presetCSS 選擇目前 Engineer／Angel token。ui/src/styles/presets.css

持久化

  • codebridgeExperiencePreset：高階 preset。
  • codebridgeBlockStyle：目前 Engineer／Angel block message overlay。
  • codebridgeTheme：舊相容鍵，啟動時自動遷移。
