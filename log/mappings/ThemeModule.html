CodeBridge Theme Module

公開 API用途位置
CodeBridgeTheme.init()讀取、遷移並套用目前的 Engineer／Angel preset。ui/src/theme/theme-manager.js
CodeBridgeTheme.setPreset(id)協調 block style、視覺 theme、持久化與 Blockly palette。ui/src/theme/theme-manager.js
CodeBridgeTheme.getPreset()取得目前 preset ID。ui/src/theme/theme-manager.js
CodeBridgeTheme.attachWorkspace(workspace)將目前 Blockly theme 與 palette 套用到工作區。ui/src/theme/theme-manager.js
CodeBridgeBlocklyTheme.getTheme(visualTheme)建立／取得 Blockly component theme。ui/src/theme/blockly-adapter.js
CodeBridgeBlocklyTheme.applyPalette(visualTheme, workspace)依 block type 的語意角色更新 workspace block、toolbox 與分類色。ui/src/theme/blockly-adapter.js
CodeBridgeBlockPalette.getColour(visualTheme, role)取得語意角色在指定 visual theme 的色碼。ui/src/theme/block-palette.js
CodeBridgeBlockPalette.getColourForRole(role)取得目前 preset 視覺主題下該角色的色碼，供 block init() 呼叫。ui/src/theme/block-palette.js
CodeBridgeBlockPalette.getRoleForBlockType(type)把 block type 對應到語意角色（精確規則優先於前綴規則）。ui/src/theme/block-palette.js
CodeBridgeBlockPalette.getRoleForCategoryName(name)把 toolbox 分類名稱對應到語意角色，dynamic 分類亦可對齊。ui/src/theme/block-palette.js
CodeBridgeBlockPalette.registerModule(manifest)第三方模組以 {id, role, typePrefix?, blockTypes?, colours} 加入 palette contract。ui/src/theme/block-palette.js
CodeBridgeBlockPalette.getCategories()讀取 toolbox 各分類的語意角色，供分類色塊對齊。ui/src/theme/block-palette.js
CodeBridgeCodeTheme.apply(visualTheme)套用程式碼預覽 visual theme。ui/src/theme/code-theme-adapter.js
data-codebridge-presetCSS 選擇目前 Engineer／Angel token。ui/src/styles/presets.css

持久化

  • codebridgeExperiencePreset：唯一的體驗 preset 鍵（engineer 或 angel）。
  • 專案尚未發佈，不保留 codebridgeTheme 遷移與 codebridgeBlockStyle 第二鍵。
  • codebridgeLang：UI 語系，與 preset 相互獨立。

積木顏色來源

  • 模組語系檔（modules/*/zh-hant.js、en.js）不含任何 *_HUE 色碼。
  • block 定義於 jsonInit() 之後呼叫 this.setColour(CodeBridgeBlockPalette.getColourForRole(role))。
  • preset 切換時由 CodeBridgeBlocklyTheme.applyPalette() 依 block.type 重算顏色，不依 block 目前的 colour 值反查。
